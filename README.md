# Task Management App – Backend

This is the backend for my **Task Management App**, built using **Node.js**, **Express**, and **PostgreSQL**.  
It provides REST APIs to add, view, update, and delete tasks.

---

##  Features
- CRUD operations for tasks  
- PostgreSQL database with Sequelize ORM  
- Organized MVC structure  
- Environment variables with `.env`  
- CORS and morgan setup
